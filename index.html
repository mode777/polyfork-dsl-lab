What is this?

    

      A compact, typed node-graph DSL for stylized three.js assets. Each example on the left is a
      .pfn graph: nodes, refs, literals, field expressions and inputs. The viewer parses
      the graph, cooks it and puts the result on the right. Geometry only — one vertex-colour material,
      flat shading, no textures.
    

  

  

    
What is included?

    

      The runtime (runtime/), the example graphs (examples/) and the viewer.
      No Polyfork source code or assets are redistributed. The showcase currently
      contains ports only: independent DSL re-expressions of publicly observable Polyfork
      constructions for demo/interop. Polyfork assets remain under Polyfork's terms.
    

  

  

    
Format

    

      n id type key=value per node · @id refs · $name inputs ·
      backticks for fields · ~`…` for parameter expressions · group … end for
      subgraphs · map/fold over groups · fields are parsed expressions
      (no JavaScript) · script/module are host-only escape hatches.
